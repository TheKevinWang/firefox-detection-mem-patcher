# Changelog

## 0.1.0 - 2026-09-10

- Added exact-build manifest parsing and PE identity validation.
- Added transactional x64 process-memory patching with rollback.
- Added attach by parent PID or Firefox executable path.
- Added monitoring for newly created Firefox descendants.
- Added debugger-controlled launch mode.
- Added manifests for Firefox 155.0.1 win64 and Tor Browser 15.0.21 win64.
- Added unit and disposable-profile integration validation.
